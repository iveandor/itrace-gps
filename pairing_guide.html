iTrace↔iLogMobile 연동 가이드

보호자의 iTrace(보호자용) 앱에서 초대 코드를 만들고, 자녀의 iLogMobile(스마트폰) 앱에 입력하면 연동이 끝납니다. 자녀 앱은 계정 가입이나 로그인이 없어 5분이면 충분합니다.

코드를 만든 뒤 1시간 안에 자녀 스마트폰에서 입력하세요. 시간이 지났거나 한 번 사용한 코드는 다시 쓸 수 없고, iTrace에서 새 코드를 만들면 됩니다. 자녀 스마트폰이 여러 대라면 한 대마다 새 코드를 만드세요.

2보호자 — iTrace에서 초대 코드 만들기

iTrace

보호자 스마트폰에서 진행합니다. 코드 화면은 자녀가 입력을 마칠 때까지 열어 둡니다.

설정 자녀 앱 관리 + 새 자녀 앱 등록
  1. iTrace 하단 탭에서 설정을 누르고 자녀 앱 관리로 들어갑니다.아직 연결된 기기가 없다면 지도 화면의 "자녀 기기 연결하기" 버튼을 눌러도 됩니다. 이때는 이어서 연동 코드 생성을 선택합니다.
  2. 목록 맨 위의 + 새 자녀 앱 등록을 누릅니다.
  3. 자녀 앱 연결 화면에 8자리 코드가 나타납니다. 코드를 한 번 누르면 복사되니 메시지로 보내기 편합니다.
  4. 코드를 자녀에게 알려 주고 "연결 대기 중" 화면을 그대로 둡니다. 자녀가 입력을 마치면 화면이 저절로 넘어갑니다.

3자녀 — iLogMobile에서 코드 입력하기

iLogMobile

자녀 스마트폰에서 진행합니다. 처음 실행하면 바로 코드 입력 화면이 나옵니다.

보호자(iTrace) 앱에서 생성한 초대 코드를 입력하세요. 앱을 다시 설치한 경우에도 보호자의 새 초대 코드가 필요합니다.

Android · iPhone 공통
  1. 자녀 스마트폰에서 iLogMobile을 실행합니다. 로그인은 없습니다. 처음 실행하면 동반 앱 연결 화면이 바로 나옵니다.
  2. 초대 코드 칸에 보호자에게 받은 8자리를 입력합니다.소문자로 입력해도 자동으로 대문자로 바뀝니다. 헷갈리기 쉬운 숫자 0·1과 영문 O·I는 코드에 쓰이지 않습니다.
  3. [필수] 이용약관과 [필수] 개인정보 처리방침에 체크합니다. 보기를 누르면 전문을 읽을 수 있습니다.
  4. 연동하기를 누릅니다. 이어서 위치 정보 수집 안내가 뜨면 내용을 확인하고 동의합니다.위치 정보 수집에 동의해야 연동이 진행됩니다.
  5. 연동이 끝나면 메인 화면으로 넘어가고, 위치 추적이 자동으로 시작됩니다.
이어서 나오는 권한 요청

위치(항상 허용), 알림, 배터리 최적화 제외 요청이 차례로 나타납니다. 화면이 꺼진 뒤에도 위치가 기록되려면 모두 허용해 주세요. 기기별 설정 방법은 기기 권한 설정 가이드에 있습니다.

4연결 확인과 이름 설정

iTrace iLogMobile

자녀가 코드를 입력하는 순간 보호자 쪽 화면이 저절로 바뀝니다. 따로 새로고침할 필요가 없습니다.

  1. iTrace의 "연결 대기 중" 화면이 자녀 앱 이름 설정 화면으로 바뀝니다.
  2. 부르고 싶은 이름을 입력하고 완료를 누릅니다. 이름은 나중에 설정 → 자녀 앱 관리에서 바꿀 수 있습니다.
  3. 지도에 자녀 위치가 표시되면 연동 완료입니다.
이렇게 보이면 정상입니다
  • iTrace — 설정 → 자녀 앱 관리 목록에 방금 지은 이름의 기기가 휴대폰 아이콘과 함께 나타납니다.
  • iLogMobile — 메인 화면이 표시되고 위치 추적이 켜져 있습니다.

5문제 해결

자녀 스마트폰에 아래 안내가 뜨면 이렇게 해 보세요. 대부분 iTrace에서 새 코드를 만들면 해결됩니다.

화면에 보이는 안내왜 그런가요이렇게 하세요
유효하지 않은 코드입니다. 다시 확인해 주세요. 코드를 잘못 입력했습니다. 8자리를 다시 확인합니다. 0·1·O·I는 코드에 없으니 비슷한 글자로 바꿔 보세요. 그래도 안 되면 iTrace에서 새 코드를 만듭니다.
만료된 코드입니다. 새 코드를 요청해 주세요. 코드를 만든 지 1시간이 지났습니다. iTrace 코드 화면의 새 코드 생성을 누르고 새 코드를 입력합니다.
이미 사용된 코드입니다. 코드는 한 번만 쓸 수 있는데, 다른 기기에서 먼저 사용했습니다. 기기마다 새 코드를 만들어 입력합니다.
이 코드를 발급한 보호자 계정이 더 이상 존재하지 않습니다. 코드를 만든 보호자가 iTrace 계정을 삭제했습니다. 지금 사용 중인 보호자 계정의 iTrace에서 새 코드를 만듭니다.
현재 요금제의 트래커 연결 한도를 초과했습니다. 요금제마다 연결할 수 있는 자녀 기기 수가 정해져 있습니다. iTrace에서 쓰지 않는 기기의 연결을 해제하거나 요금제를 변경합니다.
iTrace가 "연결 대기 중"에서 넘어가지 않아요 자녀가 아직 입력 전이거나, 두 기기 중 하나의 인터넷이 끊겼습니다. 두 스마트폰의 인터넷 연결을 확인합니다. 그 사이 코드가 만료됐다면 새 코드를 만듭니다.
